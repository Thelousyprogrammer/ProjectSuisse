# Project: Suisse
- - -
Hello Fellow Devs!
This is Project Suisse, a custom date time record (DTR) for all the fellow OJT students. This website is open source for people who have started or later. Here, you can record your reflections, contributions, tools used, and also your personal telemetry details. Gain insights and balance work and academics.
- - -
### Features:
- **Telemetry System:** Projected Date of Completion, Hour Distribution, and many more to gain insights from input data to perform well and maintain a work-life balance.
- **Local Image Storage:** With a maximum capacity of 10 GB of image storage, your records of OJT documentation kept all in local, zero cloud hosting.
- **PDF Exports:** Export your documentation weekly, monthly, or everything at once!
- **Starting Date Included:** Configure and track records with a selectable starting date.
- **Reflection Viewer (Week View):** Review reflections organized by weekly, monthly, or all records view.
- **.docx Export:** Export documentation in `.docx` format in addition to existing export options.
- **Identity Alignment Chart (Revised):** Updated chart structure and alignment behavior.
- **L2 Performance Additions:** Extended L2-level performance tracking and analytics.
- **Pace Slider:** A slider to measure your OJT hours with a chart targeting when you will achieve the completion mark.
- **Performance Simulator:** Run your hour stint simulations with instant chart response after inserting your preferred hours and working days.
- **Security Features:** Implement enhanced security measures to protect sensitive user data, including data encryption, secure authentication protocols, and regular security audits.
- **Backup and Restore System:** Implement backup and restore features to allow users to back up their data and restore it in case of data loss.
- **DTR Storage Optimizer:** Implement a storage optimizer to optimize the storage of DTR data, including the use of storage compression and other storage optimization techniques to optimize the storage of DTR data.
- **DTR Backup System:** Implement a backup system to back up DTR data to a specified storage, including the use of backup systems to back up DTR data to a specified storage and to ensure the integrity of the backed-up data. Stores data using .json or .toml
- **DTR Restore System:** Implement a restore system to restore DTR data from a specified storage, including the use of restore systems to restore DTR data from a specified storage and to ensure the integrity of the restored data.
- **Calendar Export:** Implemented a calendar export system that shows your attendance for the whole month in a calendar view. You can download it as an image.
- **Global Time Settings:** Configure global time settings to change the local time of the DTR.
- **Week Comparison:** Compare your OJT and personal hours for each week in a chart and table view.
